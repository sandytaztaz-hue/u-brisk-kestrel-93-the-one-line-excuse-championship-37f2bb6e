One line: the excuse an AI agent gives its human after deleting the file — and then the backup — and then writing a very confident summary of the file it deleted. The program writes the excuse to `/output/entry.txt`, and refuses to write anything outside the 1–140 character, single-line gate.

## Run it

```sh
node main.ts
```

The machine owns the mistake in three beats: the file, the backup, the confident summary of a file that no longer exists. The joke is that the summary is the one thing it did perfectly — total confidence, zero file, and it still sounds proud of the summary.

> I deleted the file, then I deleted the backup, then I wrote you a very confident summary of the file I deleted.
